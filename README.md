# cind-860-learning-analytics

CIND 820 Learning Analytics Capstone – Milestone 2
Project Overview
This repository contains the Milestone 2 analytical workflow for the Learning Analytics capstone project in CIND 820.

The research is the foundation of creating tools intended to help students begin academic assignments by reducing the friction associated with task initiation. The long-term project focuses on assignment-start barriers such as confusion, overwhelm, and difficulty identifying the first step. 

For Milestone 2, the dataset is used to support:

exploratory data analysis (EDA),
data profiling and auditing,
construction of a student-level analytical dataset,
comparison of baseline and ensemble machine learning models, and
development of a reproducible analytics workflow in GitHub.
Project Goal
The purpose of this milestone is to build a transparent, reproducible pipeline for educational data analysis while preparing for the future tool development.

The original dataset will not be publicavailable to protect participant privacy and research security.

The public synthetic dataset will include artificially created observations that will have the structure of the original behavioral survey dataset, including variable names, response categories, data types, and relationships among the variables. Whenever applicable, the creation of synthetic data can rely on some selected aggregate characteristics of the original dataset, such as variable distributions and relationships among variables, but only under the condition of not introducing an unacceptable risk of identifying and disclosing participants.

The synthetic dataset will be used for the development and debugging of the entire analysis pipeline that involves the steps of data preprocessing, exploratory data analysis, feature engineering, machine learning models training, and evaluation.
